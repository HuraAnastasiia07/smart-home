# 🏠 SmartHome

---

## English

SmartHome is an iOS application built with SwiftUI for monitoring and controlling a smart home system. The app connects to a server that acts as a bridge between the mobile interface and ESP32-based hardware.

### Features
- 🔑 Displays recent RFID access events
- 🔥 Shows fire alarm status in real time
- 💡 Remote control of lighting colors
- 📡 Near real-time sensor and device data updates

### Tech Stack
- **iOS** — SwiftUI
- **Hardware** — ESP32
- **Communication** — Server bridge (REST API)
